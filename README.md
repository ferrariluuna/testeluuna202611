# Luuna Sentinel (GitHub Actions)
1. Crie um repositório PÚBLICO no GitHub e suba todo o conteúdo desta pasta (inclusive `.github/`).
2. Settings > Pages > Source: **GitHub Actions**.
3. (Opcional) Settings > Secrets and variables > Actions > New repository secret:
   ANTHROPIC_API_KEY, WEBHOOK_URL, SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, EMAIL_FROM, EMAIL_TO.
4. Actions > "Monitor Luuna" > Run workflow. Em ~2 min o painel abre em https://SEU-USUARIO.github.io/NOME-DO-REPO/
